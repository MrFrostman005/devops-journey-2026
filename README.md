# DevOps Journey 2026

Репозиторий документирует мой путь в DevOps.
Текущая позиция: инженер облачной инфраструктуры (OpenStack/KVM, Ростелеком).
Цель: DevOps / Cloud Engineer.

## Стек

- **Инфраструктура:** OpenStack (Nova, Neutron, Cinder, Glance, Keystone), KVM
- **ОС:** Linux (Debian, CentOS, Ubuntu)
- **Контейнеризация:** Docker, Docker Compose
- **Автоматизация:** Ansible, Bash
- **Сети:** TCP/IP, VLAN, L3VPN, маршрутизация
- **IaC:** Terraform (в изучении)
- **Оркестрация:** Kubernetes (в изучении)

## Скрипты

### check_vm.sh
Проверка доступности серверов по списку IP через ping.
Выводит статус каждого хоста — доступен или нет.

### port_check.sh
Проверка доступности TCP-порта на удалённом хосте.
Использует nc для проверки без установки соединения.
